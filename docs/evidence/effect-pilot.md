# 模擬の受け手による理解度の予備試験（2026-10-17、Issue #7）

**人の受け手の代わりにならない。** 受け手は別のAIモデルで、実際の同僚の知識・文脈・聞き方を持たない。項目と正解を作ったのはSkillの設計者と同じAI（独立していない）。この試験で言えるのは『手順（単一版の配布・版を伏せた割付・自動採点）が通る』『修正案が理解を損なっていないかの目安』までで、**実務での効果は示さない**。人による測定は [docs/EFFECT-MEASUREMENT.md](../EFFECT-MEASUREMENT.md)。

## 設計（実行前に固定。`tools/effect_pilot.py` の冒頭）

- 項目 = 9件（8件は元の言い方と、Skillの修正案の対。1件は修正案が無い適合ケースで、両方の版を同一の文にした対照 CTL-A07）。質問 = 16問（選択式。選択肢に『文だけでは分からない』を含む）。正解は資料（確認票の根拠）から付けた。項目は [tools/data/effect-pilot-items.json](../../tools/data/effect-pilot-items.json)
- 受け手 = 別のAIモデル。**1人（1回の新しいセッション）に、1項目につき一つの版だけ**を示す。版は無作為（受け手の半数ずつ）。配布物に版の名前・正解・根拠は含まれない（テストで確認）。受け手には資料を見せない
- 判断基準: 主指標 = 質問ごとの正答率の差（revised − original）の平均。『改善あり』= 平均 ≥ 0.15 かつ 改善した質問数 > 悪化した質問数。『害の疑い』= revised が original より 0.25 以上低い質問がある

## 見つかったこと

1. **修正案は、元の言い方が欠いている・誤って伝える情報を、受け手に正しく伝えた**。元の文だけだと、受け手は『分からない』を選ぶか（66/128）、元の文の誤り（A06の『冪等です』、A04の『納品は完了です』）を信じた。これは設計上、修正案が資料の事実を明示する項目なので大きく出る。**効果の大きさそのものは、実務の効果を表さない**
2. **害は見つからなかった**。意図の保持を見る質問（A01 q3）は元・修正案とも全問正答で、修正案に誤った含み（話者が最終承認する等）は読み取られなかった。どの質問でも修正案の正答率は元を下回らなかった
3. **受け手のモデルによって、元の言い方の理解が違う**。Codexは用語の一般知識で元の文を正しく読めた項目（A09、A12）が多く、Antigravityは元の文をそのまま信じる傾向があった。人の受け手でも、知識や文脈で差が出ると予想される
4. **項目の不備（A04 q1）**: 質問『サービス一式の納品は完了していますか』の正解を『完了していない』と付けたが、資料が言うのは『設計書だけの提出は納品完了を意味しない』であり、**サービスが未納品とまでは言っていない**。修正案（『設計書の提出だけでは、サービス一式の納品完了にはなりません』）も同じ範囲で述べており、Codexの受け手5人は『分からない』を選んだ（資料の範囲では妥当な読み）。Antigravityの3人は『完了していない』と答えた。正解の付け方が資料を超えていた。**結果を見た後に正解を直さず、そのまま集計**した。この質問を除いた平均は +0.68（14問）で、結論は変わらない。この実行で使った項目ファイルは [effect-pilot-items-used.json](effect-pilot-items-used.json)（SHA-256 `b6502eacf0e3bcc390220eb25751c169ae5cae6193500e3b15644089318cb87d`）。**現在の `tools/data/effect-pilot-items.json` では、A04 q1 を削除した**（A04 q2 が資料に沿った同じ内容を問うているため）

## 限界

- 受け手はAIで、**人の受け手の代わりにならない**。人数も少ない（16人、質問16問）。質問ごとの正答率は8人前後に基づく
- 項目・質問・正解を作ったのは、Skillの設計者と同じAI。修正案が答えを含む質問が多く、効果は大きく出やすい設計
- Antigravityの受け手からはSkillを外せなかった（ログではSkillの読み込みなし）。ホストが持つ過去の会話・知識が回答に影響した可能性は排除できない
- 受け手のサンプリングのばらつき（同じ入力でも答えが揺れる）は、同一の文の対照1問でしか見ていない
- 単一の入力ごとの比較で、複数の言い方・長い文脈・口頭での伝達は扱っていない
