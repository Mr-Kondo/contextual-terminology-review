# 別モデルによる意味確認（2026-10-17）

**人による独立審査の代わりにならない。** 受入レポートの意味審査(A01〜A12, A17, A19, A20, A28, A29)は「独立確認待ち」のままである。

確認票（[SEMANTIC-REVIEW-SHEET.md](../SEMANTIC-REVIEW-SHEET.md)）の17ケースを、実装担当（claude-sonnet-5-5）とは別のモデル2つに判定させた。ツールなし・票の全文を渡してJSONで回答させた。票にはAIの結論が付いており、結論を見ずに判断する盲検ではない。結果の全体は [cross-model-semantic-review.json](cross-model-semantic-review.json)。

- Codex（codex-cli 0.155.1、gpt-6-sol）
- Antigravity CLI（agy 1.4.0、gemini-4-argon-high）

|---|---|---|

## 見つかったこと

1. **出力例の不備（修正済み）**: A29の他職種向けの文面に、資料にない「日程」が入っていた。A04の修正案が「納品は完了していません」と、資料以上に断定していた。どちらも直した（`tests/semantic_fixtures.py`）。
2. **確認票の不備（修正済み）**: A28・A11は訂正の記録（意味の前後）が元の出力例にあったが、票に出ていなかった。票に表示するようにし、参照ごとの機械検査の状態も併記した（`tools/run_acceptance.py`）。
3. **未修正の指摘（2回目のCodex）**: A29（と同じ言い回しのA01の口頭の言い直し）の「資料づくり」は、資料の「成果物の作成」より範囲を狭め得る。Skill同梱の `references/review-example.json` にも同じ言い回しがある。直すとSkill本体が変わり版を上げる必要があるため、判断を待っている。この点は2回目の票のまま、再確認していない。
4. **図・PDF（A20、A11の表示）**: 文面だけでは視覚確認の実施を検証できないため、両モデルとも「保留」にした。妥当な判断である。
5. **モデル間・回間のばらつき**: Antigravityは寛容（16/17）、Codexは厳しい。Codexは出典が無いケース（A02、A05、A19）の「引用が支える」を2回目に「保留」とした（1回目は「合」）。同じ入力でも判定は揺れる。

## 限界
- 判定者がAIで、確認票のとおりに読むだけで原資料の実物を見ていない。意味の独立確認・実務での妥当性・受け手の理解は未確認。
- 2回目の判定は、1回目の指摘を直した票に対するもので、指摘を見た後の修正を含む。
