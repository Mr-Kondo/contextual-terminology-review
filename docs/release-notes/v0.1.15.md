# v0.1.15 — 一致検索が表記ゆれを拾う

- `ctr.py search exact` が、完全一致で見つからない語について、候補探し専用の正規化で再照合する（NFKC・大小無視・空白／中黒／ハイフン／スラッシュの除去・語末の長音の除去）。結果には `via: "normalized"` と原文の表記を返す。
- 語中の長音は残す（`ビル` が `ビール` に当たらない）。完全一致の結果と `suppressed` の挙動は変えない。
- 引用の一致検査（`check refs`）は変えない。正規化の一致は確認候補であり、引用の根拠にしない。
- 限界: 既存の課題セットでの効果は小さい（表記ゆれ 2/20 の探索的測定）。実データでの効果は未確認。
