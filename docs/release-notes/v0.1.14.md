# v0.1.14 — 独自インストーラーを削除し Skills CLI に一本化

- `tools/ctr_install.py`（導入・更新・削除・照合・配布物作成）とそのテストを削除。導入・更新・削除は `npx skills` で行う。
- リリースの添付は zip のみ。`ctr_install.py` と `INSTALL-ON-REMOTE.txt` は添付しない。zip は `git archive` で作る。
- 旧インストーラーで配置した環境は、docs/INSTALL.md の「既存配置からの移行」で Skills CLI へ移る。
- Skill本体（判断・スクリプト・参照資料）は変更しない。

過去のリリースノートと実環境の検証記録は、当時の事実として残す。
