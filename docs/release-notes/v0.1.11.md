# v0.1.11 — リリースの自動化（検証版）

[v0.1.10](https://github.com/Mr-Kondo/contextual-terminology-review/releases/tag/v0.1.10) からの違い:

- **リリースを GitHub Actions で自動化**: `main` の VERSION が変わると、タグ・zip・リリースを作る（`.github/workflows/release.yml`）。ノートは `docs/release-notes/v<版>.md`。手順は docs/RELEASING.md。**このリリース自体が、その最初の実行である**
- `main` に、CI の `test` を必須にするブランチ保護と、自動マージ、マージ後のブランチ自動削除を設定した（リポジトリの設定。配布物には入らない）
- Skill の判断・コマンド・参照、導入ツールの動作は変えていない。版を 0.1.11 に

## 添付
- `contextual-terminology-review-0.1.11.zip`（Skill本体。手動配置用）
- `ctr_install.py`（導入・更新・削除・照合。標準ライブラリだけで動く）
- `INSTALL-ON-REMOTE.txt`（別のホストへ移すときの手順）

## 検証した範囲
- 169テスト通過（Linux・Windows の CI）。workflow の手順は、手元で zip の生成と SHA-256 の計算まで確かめた。GitHub 上での実行は、このリリースが最初

## 未実施・注意（完成品・効果測定済みではない）
- **Windows の実機（利用者の PC）では実行していない**
- 発動精度の測定は v0.1.6 から変えていない（Skill の description は同じ）
