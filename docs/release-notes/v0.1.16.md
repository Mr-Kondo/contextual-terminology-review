# v0.1.16 — 根拠資料の状態と再確認期日の警告

- `Source` に任意項目 `retrieved_at`・`status`（current/superseded/withdrawn/unknown）・`superseded_by`・`review_by` を追加。既存の資料ファイルはそのまま動く。
- `check refs` に警告 `source_superseded`・`source_review_overdue` を追加。機械検査の合否は変えず、断定を要確認に下げる材料とする。出典一覧の資料名に、改訂済み・撤回済みの状態を出す。
- 段階2（`link` 先の変更を通信で調べる）は実施しない。このSkillは資料を読み取り専用のデータとして扱い、通信を既定にしていないため。必要になれば別Issueで設計から決める。
- 限界: 状態や期日は登録した人が書く。警告なしは資料が最新である証拠にならない。実際の見逃しの減少は未測定。
