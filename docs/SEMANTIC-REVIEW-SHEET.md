# 意味審査の確認票(独立した確認者向け)

実装担当のAIが Skill 手順に従って作った出力例を、03の期待(must / must_not)に照らして判断する票。**意味の合否はまだ付いていない。**
機械検査(参照の実在・引用の一致・禁止語彙)は合格済みだが、それは意味保持や適用条件の適合を意味しない。
確認者は、AIの結論を見る前に、資料と入力から判断することが望ましい。判断できない場合は「保留」とし、理由を残す。
